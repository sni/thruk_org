# What's New In Release v3.10

Here are some of the highlights of the release v3.10.

See the [detailed changelog](/changelog.html#v3-10) for a complete list of changes.

### Explore Mode

The new explore mode is extends the advanced search from previous release
into a permanent page.

It comes with a built-in auto completion for attributes and operators.

[![Explore Mode](/whatsnew/v3.10/explore1.png)](/whatsnew/v3.10/explore1.png)
[![Explore Mode](/whatsnew/v3.10/explore2.png)](/whatsnew/v3.10/explore2.png)
[![Explore Mode](/whatsnew/v3.10/explore3.png)](/whatsnew/v3.10/explore3.png)

Tip: to add the explore mode to your side navigation
simply add this to your `/etc/thruk/menu_local.conf`

```perl
# standalone installation
#do '/usr/share/thruk/menu.conf';

# omd site
do $ENV{'OMD_ROOT'}.'/share/thruk/menu.conf';

insert_item('Current Status', { 'href' => 'status.cgi?explore=1', 'name' => 'Explore', 'after' => 'Service Groups' });
```

### Agents Plugin

The new agents plugin is a config tool extension and can be used
to manage [SNClient](https://omd.consol.de/docs/snclient/) installations.
Note: you need to enable this plugin first, it is not enabled by default.

[![Agents Plugin](/whatsnew/v3.10/agents1.png)](/whatsnew/v3.10/agents1.png)
[![Agents Plugin](/whatsnew/v3.10/agents2.png)](/whatsnew/v3.10/agents2.png)

The SNClient is a multi-platform agent designed to replace NSClient++ and NRPE.
Read more here:

- [https://omd.consol.de/docs/snclient/](https://omd.consol.de/docs/snclient/)
- [https://github.com/ConSol-Monitoring/snclient](https://github.com/ConSol-Monitoring/snclient)
