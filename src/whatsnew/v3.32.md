# What's New In Release v3.32

See the [changelog](/changelog.html#v3-32) for a history of all changes.

### Change Log v3.32

```
3.32     Wed Nov 18 16:51:11 CET 2026
          - add Status Replay with a playable log-based host and service status timeline
          - disable the shipped administrator password on fresh installs and package upgrades;
            set a password with htpasswd /etc/thruk/htpasswd thrukadmin before login
          - fix quick search treating strings containing "like" as lexical query (#1538)
          - improve summary page performance by fetching only required columns (#1536)
          - add check_timeout to livestatus columns
          - add date and time to cron.log
          - improve graph popup positioning and hover behavior
          - Security:
            - fix insecure package restore staging
            - do not send thruk_auth session cookies to external hosts
            - fix login referer open redirect after decoding
            - preserve role restrictions in derived credentials
            - fix CSRF protection for profile preferences and team changes
            - enforce command permissions and CSRF checks for core rescheduling
            - enforce read-only restrictions for server actions
            - fix authorization when replacing recurring downtimes
            - fix custom variable exposure in status XLS exports
            - fix plugin output escaping on landing page and performance map
            - fix path traversal in broadcast IDs
            - confine remote configuration sync paths to the peer cache
            - require admin permission for remote CLI stop and restart
            - prevent shell interpretation in job diagnostics
            - reject embedded newlines in external command frames
            - strip CR/LF from all free-text command form fields (performance_data, plugin_output,
              com_author, com_data_disable_cmd) which the bulk_send guard does not reach (GHSA-4w69-9wqr-7w5c)
          - OAuth:
            - add team_regex and team_filter options to transform and filter team names
            - bind callbacks to the browser which initiated the login
          - Rest:
            - restrict privileged REST CLI features to local execution
            - require admin authorization for logcache updates
          - Log Cache:
            - remove redundant joins in service authorization queries (#1537)
            - validate query limits before SQL interpolation
          - Config Tool:
            - add naemon check_timeout attribute to hosts and services
            - fix storable cache corruption when config tool retention data is read and written concurrently (#1497)
            - serialize concurrent model changes (config tool web pages, REST and CLI) with automatic lock retrying
          - Agents:
            - quote SNClient inventory values in generated check commands
          - Business Process:
            - fix authorization for changes and REST exports
          - Panorama:
            - require write access for dashboard maintenance changes
            - validate dashboard import media paths
            - fix media overwrite checks for private dashboards
          - Reports:
            - fix log authorization in event reports
            - reject submitted report runtime state
            - fix remote response parsing in puppeteer renderer
            - make puppeteer loader work on node 16 through 26 and with ESM
              module layouts, so graph and PDF export keep working after the OMD node update
          - Trends:
            - fix authorization for saved graphs
```
