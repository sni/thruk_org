# What's New In Release v3.02

Here are some of the highlights of the release v3.02.

See the [detailed changelog](/changelog.html#v3-02) for a complete list of changes.

### Improved Dependencies Support

Dependencies have always been a bit intransparent.

This update adds a new hint if dependencies prevent a host/service from beeing checked.

There is also a new page showing a breakdown of service dependencies and relations.
