# What's New In Release v2.40

Here are some of the highlights of the release v2.40.

See the [detailed changelog](/changelog.html#v2-40) for a complete list of changes.

### Colored Terminal Output

In order to improve visibility, terminal output colored.

[![terminal colors](/whatsnew/v2.40/terminal.png)](/whatsnew/v2.40/terminal.png)

### Logcache Improvements

The logcache got some more improvements and uses the compact time frame
on updates as well. Also the `thruk logcache stats` command got updated.

[![logcache stats](/whatsnew/v2.40/logcache.png)](/whatsnew/v2.40/logcache.png)

### Rest Output Options

The rest api got some output parameter to easier control the data format.

[![rest output](/whatsnew/v2.40/rest.png)](/whatsnew/v2.40/rest.png)
