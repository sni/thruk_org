# What's New In Release v2.44

Here are some of the highlights of the release v2.44.

See the [detailed changelog](/changelog.html#v2-44) for a complete list of changes.

### Security Improvements

This release includes security improvements and bugfixes.

- fix xss issue with quickcommands.
- set secure cookie attribute when using https (use *cookie_secure_only* option to force it)
- use csrf token in every form
